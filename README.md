# 🎉 Celebration Card Generator

A beautiful, interactive celebration card generator built using **pure HTML, CSS, and JavaScript**.  
It features animated confetti bursts, custom text fields, dynamic theming, and a clean welcome screen for entering the recipient’s name.

Perfect for birthdays, congratulations, anniversaries, or any occasion worth celebrating!

---

## ✨ Features

- 🎨 Customizable text, colours, and fonts  
- 🎉 Confetti explosion animation on click  
- 🖼️ Clean welcome screen where users enter a recipient's name  
- 💌 Dynamic celebration card with name, message, and style updates  
- 📱 Fully responsive design  
- ⚡ No build tools or frameworks needed — opens directly in any browser  
- 🔧 Optional integration with `elementSdk` for live configuration mapping  

---

## 🚀 Getting Started

1. Clone the repository:

```bash
git clone https://github.com/your-username/celebration-card-generator.git
cd celebration-card-generator
```

Open the project in a browser:

```bash
open main.html
```
or simply double-click main.html.

## 🔧 Customization
The card uses a defaultConfig object for:
- Background colors
- Accent colors
- Text colors
- Card appearance
- Font family and size
- Celebration type
- Recipient name
- Main message
- Closing message

If using with elementSdk, all values dynamically update in real-time.
